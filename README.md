## Sobre mí

Hola, soy **Chris**. Me interesa el desarrollo **full stack** porque disfruto conectar la experiencia de usuario con la lógica, los datos y todo lo que hace funcionar una aplicación de principio a fin.

He trabajado en proyectos web con **Python, JavaScript, TypeScript, React, Node.js, C#, HTML, CSS y Microsoft SQL Server**. Me gusta aprender construyendo, colaborar con otras personas y explicar el propósito de cada proyecto con claridad. Estoy abierto a oportunidades de desarrollo y a crear cosas nuevas en equipo.

## Proyectos

<a href="https://github.com/Gluphony/YuNet"><img src="./assets/yunet.svg" alt="Ver YuNet en GitHub" width="100%" /></a>

**Sistema web de gestión comercial.** Proyecto en equipo para organizar productos, inventario, compras, pedidos y reportes. Usa **C#, ASP.NET Core y Microsoft SQL Server** con capas de presentación, lógica de negocio, entidades y datos. La [rama con el desarrollo más completo](https://github.com/Gluphony/YuNet/tree/rama_de_intento_de_Reporte) muestra estos módulos.

<a href="https://github.com/Gluphony/mi_primera_ia"><img src="./assets/ia.svg" alt="Ver Mi primera IA en GitHub" width="100%" /></a>

**Asistente virtual para la Universidad de Managua.** Une una interfaz en TypeScript con una API en **FastAPI**. Recupera información de documentos para responder preguntas y también incluye registro, conversaciones y reportes de uso.

<a href="https://github.com/Gluphony1/lol"><img src="./assets/luma.svg" alt="Ver Luma Music en GitHub" width="100%" /></a>

**Sitio de música desarrollado en colaboración.** Una experiencia web inspirada en las plataformas de streaming musical, construida principalmente con **TypeScript y CSS**.
